# Mega Plan: Panel 10/10 — close every judge's dock

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close every closable dock from the 10-judge panel (avg 6.61, range 4.75–7.75, 10/10 Stage-1 PASS) and convert the entry from "real but unwitnessed" into "witnessed, load-bearing, and submitted."

**Architecture:** Four phases ordered by points-per-effort: (1) cheap truth-fixes that remove the rival's kill-shot and the maintainer's hygiene veto; (2) medium experiments that decide the image's load-bearing status and widen the fault universe; (3) user-owned submission assets (video, public push, outside run) that only a human can produce; (4) docs reframes where no build can close the dock. Each task ends with an independently testable deliverable + commit.

**Tech Stack:** Python 3.12, Verilator 5.x, Muse Spark API (text `muse-spark-1.3-contributor`, image `muse-image-1.0`), bash/CI, git. No new dependencies (per repo law). API budget: phases 1–2 spend ≈ $3–5 of the $100 user cap.

**Spec:** The ten judges' verdicts + reasonings in-session (m04110–m04190): mentor 7.75, lawyer 7.75, vet 7.2, maintainer 6.7, Meta-eng 6.5, PM 6.45, creator 6.45, VC 6.3, academic 6.25, rival 4.75. Executor reads the verdict messages, not just this plan.

## Global Constraints

- REAL API calls only; no mocks; loop fails loudly, never heuristic fallback (AGENTS.md §0).
- Every green claim needs a full 11-file proof bundle; never edit old bundles/runs (AGENTS.md §1).
- Patches: allowlisted RTL only, ≤40 lines, lint-clean, ≤2 retries; forbidden strings scanned (AGENTS.md §2).
- Trace window ≤200 lines, prompt ≤2500 tokens; prompts versioned in agent/prompts/vX.txt (AGENTS.md §3).
- Commits dated inside Oct 27–Nov 4 window; no weft/ copy; baseline stays Oct 26 (AGENTS.md §7).
- No new dependencies. No secrets on disk except .env (gitignored, mode 600).
- User vetoes (binding): NO thousands-scale runs, NO open-weights work, demo work parked until user shoots video.

## Review Focus

- Patch-source honesty: `patch_source` in meta.json must distinguish model-verbatim vs canonical-bootstrap-gated; any new fallback path must be logged, not silent.
- Denominator honesty: every rate states its denominator; static yield vs live kill vs kept-mutant confirmation never conflated.
- Bundle immutability: new runs get new run-ids; old runs never touched; score.py reads only runs/*/meta.json.
- Cost honesty: cost.json ESTIMATES placeholder stays labeled; no billed-rate claims.

## Honest ceiling (read before executing)

10/10 from ALL ten judges is not achievable in-window: the rival caps at ~7 without taped-out silicon evidence, adoption/TAM needs real users, open-weights is user-vetoed (Meta-eng dock stands), and the video + outside run need a human. Realistic outcome: panel average 6.61 → ~8.5–9.0, with individual 10s reachable from mentor/lawyer/creator/vet. The plan says which docks stay open.
