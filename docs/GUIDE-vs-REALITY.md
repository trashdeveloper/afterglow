# GUIDE vs REALITY — what this repo actually is

Honest accounting. Every checkable claim below is enforced by
`tests/test_docs_guide.py` — if a claim rots, the suite goes red.

## What Afterglow is

A RED→VERIFY agent loop: Verilator sim goes RED, the agent collects a
trace window, Muse Spark diagnoses, an image model explains, a ≤40-line
RTL patch is applied, the sim re-runs, and a proof bundle lands in
`runs/<run-id>/`. Guardrails reject bad patches before they count.

## What is real (verified on disk)

- gallery lives at `gallery/index.html` — 8 locked-case cards with
  measured times, patch lines, costs; honest n/a where logs predate
  cost tracking.
- quickstart runs `./afterglow demo` — triage-only run of the fastest
  locked case, diagnosis saved, patch withheld (~1 model call).
- demo case: `picosoc-uart-div` — fastest locked GREEN at runtime,
  eval/results.md, not hardcoded.
- Locked board: locked 3/3, full 7/8, zero human touches
  (see eval/results.md, generated by eval/score.py from runs/ only).
- No mocks: non-test agent code contains no mock/canned paths;
  transport flakes fail loud (exit 2, patch withheld).
- Keys: `.env`-based (`MODEL_API_KEY`), gitignored, never logged;
  history contains no key material.
- suite: 2104 tests (`python3 -m unittest discover -s tests`),
  `bash scripts/ci.sh` gates ALL PASS.
- Landmarks: 557a97e (Node TUI spike), 818d914 (advisory fixes),
  d0b28e8 (CLI polish) — all `git cat-file -t` verified.

## Stranger quarantine (how we keep "unseen" honest)

- Fresh-design proofs: H1 (SERV-based), H2 (non-CPU spimemio),
  stranger2 (darkriscv) — each quarantined from prior families.
- Mutant boards: 35 kept (H10) + 72 kept (H10 phase-2), each
  RED-proven through the sanctioned prepare path.
- Rule: a new fault on a prior family line must carry a novel
  after-text (exact-text exclusion) or it does not count.

## What is NOT (yet)

- Not a push-button product: `./afterglow demo` is the only
  one-command path; full runs need a key and patience.
- Not load-bearing vision: waveform PNGs attach to attempts and an
  ablation measured them; text diagnosis carries the fixes.
- Not finished: open items live in the plan doc, not in marketing copy.
