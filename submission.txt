Chip bring-up takes weeks and a verification team. Only giants can afford it. Afterglow is a Muse Spark agent that reads RISC-V sim traces, diagnoses failures, patches RTL, re-runs the sim, and verifies itself. One Docker command goes red to green: picosoc-uart-div fixed verbatim in 92.6s, locked 3/3 green, full 8/8 green, checksums match, zero human RTL edits. Text decides every patch under guardrails; Image draws the failure explanation from the actual trace for human check. All runs logged with prompts, diffs, and latencies. Built Oct 27-Nov 4 on frozen open-source PicoRV32.
